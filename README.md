# STePNet

STePNet — Spatially Transferable Pedestrian Demand and Network Modeling — is an open-source Python framework for estimating pedestrian network flows in cities where detailed local demand data are limited or unavailable.

The framework integrates transferable pedestrian trip generation, destination choice, route assignment, OD demand adjustment, and graph-based diagnostics into a unified modeling pipeline. Inspired by urban network analysis tools such as UNA and Madina, STePNet extends network-based pedestrian flow modeling by explicitly incorporating transferable behavioral demand components and calibration with observed pedestrian counts.

STePNet is designed to support pedestrian planning, infrastructure assessment, and transferability analysis across different urban contexts.
